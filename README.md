## 🚀 Proje Kapsamı
Proje dahilinde aşağıdaki temel veri tabanı işlemleri gerçekleştirilmiştir:
*   **Database Creation:** "Okul" veri tabanının her iki platformda yapılandırılması.
*   **Tablo Yapısı:** "Ogrenciler" tablosunun oluşturulması (ID, Ad, Soyad, Bolum, NotOrtalamasi).
*   **CRUD Operasyonları:**
    *   **Select:** Verilerin listelenmesi.
    *   **Insert:** Yeni kayıtların eklenmesi.
    *   **Update:** Verilerin güncellenmesi (Örn: Not ortalaması revizesi).
    *   **Delete:** Kayıtların silinmesi.
